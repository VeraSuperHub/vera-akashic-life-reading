# Traditional Astrology Module

Use this module when the user asks for 古占, 古典占星, traditional Western astrology, Hellenistic-style astrology, or a classical astrology layer on top of modern 西占.

## Scope

`scripts/astro_profile.py` can emit a `traditional_western` block when `systems` includes `traditional`, `hellenistic`, `ancient`, or `古占`.

The deterministic layer includes:

- Tropical zodiac.
- Whole-sign houses from Ascendant.
- Traditional seven-planet rulership.
- Sect: day or night chart.
- Essential dignity: domicile, detriment, exaltation, fall.
- Planet house angularity: angular, succedent, cadent.
- Lots of Fortune and Spirit.
- Annual profections for target dates or target years.

The helper does not currently calculate:

- Bounds/terms.
- Decans/faces.
- Fixed stars.
- Primary directions.
- Zodiacal releasing.
- Medieval reception chains beyond basic rulership/dignity.

If the user needs those, ask for a verified 古占 chart or treat the reading as partial.

## Interpretation Use

Use 古占 as a condition-and-timing layer, not as a fate verdict.

- Sect can qualify how easily a planet expresses its traditional role.
- Essential dignity can qualify whether a planet has stable authority, strain, or mixed condition.
- Whole-sign house placement can name the life arena where a planet acts.
- Angularity can show visibility or action strength, but not guaranteed outcomes.
- Lots can add symbolic focus: Fortune for embodied circumstance and Spirit for intention/volition.
- Annual profections can name the activated house and time lord for a target year, but should be framed as symbolic timing context.

## Cross-System Use

古占 should not override modern 西占 or 印占. Use it to sharpen the question:

- Modern astrology can describe psychological patterning.
- 古占 can describe condition, visibility, and time-lord emphasis.
- 印占 can describe sidereal lunar/nakshatra and dasha context.

When these layers disagree, do not force them into one answer. Say which layer is doing which job.

## Safety Boundaries

- Do not make deterministic predictions about death, disease, divorce, pregnancy, wealth, or legal outcomes.
- Do not use malefic/benefic language as fear language. Translate it into condition, pressure, support, or required discipline.
- If a planet or angle is boundary-sensitive, ask for chart confirmation before interpreting its sign or house.
